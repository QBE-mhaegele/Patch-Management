- ✅ Connects to Microsoft Security Response Center API

## 🔍 Risk Scoring Algorithm

The system assigns each machine a risk score (0-150 points):

| Factor | Points | What It Checks |
|--------|--------|----------------|
| **Patch Age** | 0-40 | Days since last update |
| **Security Config** | 0-30 | SMB1, BitLocker, Secure Boot, Antivirus |
| **OS Support** | 0-50 | Windows version support status |
| **Pending Reboot** | 0-10 | Incomplete installations |
| **Hardware Risk** | 0-20 | Intel RST, old BIOS, VirtIO drivers |

**Priority Levels:**
- **CRITICAL (80+):** Requires rebuild/major remediation
- **HIGH (50-79):** Needs driver updates before patching
- **MEDIUM (25-49):** Standard deployment
- **LOW (0-24):** Perfect for pilot testing
